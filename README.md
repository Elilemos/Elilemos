### 📂 Projetos

🔹 **Lista de Presentes de Casamento – Aplicação Web Full Stack**

Aplicação desenvolvida para meu próprio casamento, pensada para oferecer uma experiência simples e sem constrangimentos aos convidados.

A ideia principal foi permitir que os convidados escolhessem um presente **sem a obrigatoriedade de pagamento imediato**, tornando o processo mais confortável e acessível.

### 🧠 Regras de negócio implementadas
- Exibição de uma lista pública de presentes
- Ao clicar em **“Presentear”**, o convidado é direcionado para uma nova página onde informa:
  - Nome
  - Número de telefone
- Após confirmar a reserva:
  - O presente escolhido é **automaticamente removido da lista pública**
- Criação de uma **área administrativa privada**, acessível apenas por mim, onde é possível:
  - Visualizar quem reservou cada presente
  - Consultar o número de telefone do convidado

### 🚀 Objetivo do projeto
Resolver um problema real, oferecendo uma solução personalizada, funcional e pensada na experiência do usuário.
