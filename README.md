## 📂 Projetos em destaque

### 🎁 Lista de Presentes de Casamento — Aplicação Full Stack

Aplicação desenvolvida para meu próprio casamento, com o objetivo de oferecer uma experiência simples e prática aos convidados.

A solução permite reservar presentes sem a necessidade de pagamento imediato.

**Principais funcionalidades:**
- Listagem pública de presentes disponíveis.
- Reserva de presentes com nome e telefone do convidado.
- Remoção automática dos presentes reservados da lista pública.
- Área administrativa privada para consulta das reservas.

**Tecnologias:** JavaScript, Node.js, Express e PostgreSQL.

🌐 **Projeto online:**  
https://lista-presentes-casamento-production.up.railway.app/
